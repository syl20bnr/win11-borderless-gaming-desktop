# Icon assets

`icon-master.png` is the transparent high-resolution source artwork. Regenerate
all derived application and tray assets from the repository root with:

```sh
cargo xtask icons
```

The command produces the multi-resolution `app.ico`, a 256 px `app.png`, and
the `tray-desktop.png`, bright/dim `tray-activating*.png`, and
`tray-gaming.png` status variants. Do not edit those generated files by hand.

`desktop-mode-wordmark.png` and `gaming-mode-wordmark.png` are the original
transparent diffuser-generated text artworks used in the GUI status banner.
They are embedded directly by the application and are not generated by
`cargo xtask icons`.
